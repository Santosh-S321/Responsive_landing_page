# Responsive Landing Page

##  Project Overview

This project is a clean and responsive landing page built using **HTML5 and CSS3**.
It includes a header navigation bar, hero section, feature section, about section, and footer.

This project was created as part of my internship task to demonstrate responsive design and modern layout techniques.

---

##  Features

* Responsive layout for mobile, tablet, and desktop
* Modern UI design
* Sticky navigation bar
* Animated hero text and elements
* CSS-only hamburger menu
* Grid and Flexbox layout
* Smooth scrolling
* Reusable CSS variables

---

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
